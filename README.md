# 🏥 Patient Emergency Room Visit Analysis Dashboard

## 📌 Project Overview

This project presents an interactive **Patient Emergency Room Visit Analysis Dashboard** developed using **Microsoft Power BI**. The dashboard provides a comprehensive overview of emergency room visits and helps analyze patient demographics, satisfaction levels, waiting times, admission types, and department referrals.

The objective of this project is to transform healthcare data into meaningful insights that can support better operational understanding and decision-making.

> **Note:** The dataset used in this project was collected from publicly available external/other resources and is used solely for data analysis and portfolio purposes.

---

## 🎯 Project Objectives

The main objectives of this project are:

- Analyze overall emergency room patient visits
- Monitor patient satisfaction levels
- Track average patient waiting time
- Compare administrative and non-administrative appointments
- Analyze patient visits by age group
- Understand patient demographics and gender distribution
- Identify department-wise patient referrals
- Analyze weekday versus weekend patient visits
- Explore patient distribution across different demographic groups

---

## 📊 Key Performance Indicators (KPIs)

The dashboard highlights important healthcare metrics such as:

- Total Patient Visits
- Average Patient Satisfaction Score
- Service Not Rated Percentage
- Average Patient Waiting Time
- Administrative vs Non-Administrative Appointments
- Referred vs Walk-in Patients
- Gender-wise Patient Distribution

## 📈 Dashboard Features

### Patient Visit Analysis
- Total patient visits
- Weekday vs weekend visit comparison
- Year-wise patient visit trends
- Age group analysis

### Patient Experience Analysis
- Average satisfaction score
- Service not rated percentage
- Average waiting time analysis

### Demographic Analysis
- Gender distribution
- Age group distribution
- Patient race analysis

### Department Analysis
- Department-wise patient referrals
- Identification of departments receiving the highest number of referrals

### Interactive Filtering
The dashboard includes interactive filters for:

- Year
- Month
- Performance metric selection

These filters allow users to dynamically explore and analyze patient visit patterns.
